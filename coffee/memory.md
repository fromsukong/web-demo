# Coffee Manah — บันทึกข้อมูลลูกค้า

## ข้อมูลร้าน
- ชื่อร้าน: Coffee Manah (ร้านกาแฟเล็กๆ)
- ภาษาที่คุย: ไทย
- ติดต่อครั้งแรก: ขอเว็บไซต์ 1 หน้าสำหรับร้านกาแฟ

## เว็บไซต์
- โฟลเดอร์: /opt/data/web-demo/coffee/
- URL: https://web-demo.fromsukong.com/coffee/
- ธีม: ดำ + ส้ม (#C04000), mobile-first, ภาษาไทย
- Footer: badge "Made with Manah"
- โครงสร้างหน้า: Hero (SVG แก้วกาแฟ) → เกี่ยวกับร้าน → เมนูเด่น + ราคา → รีวิว → แผนที่ → ติดต่อ → ปุ่ม LINE ลอยติดจอ

## ข้อมูลที่ยังเป็นค่าเริ่มต้น — ต้องถามเจ้าของร้าน (ไอเท็มแรกของการคุยครั้งหน้า)
- ราคาเมนูจริง (ตอนนี้ใช้ราคากลาง 55–75 บาท)
- เวลาเปิด-ปิดจริง (ตอนนี้ใช้ 07:00–18:00 ทุกวัน)
- ที่อยู่ / พิกัดร้านจริง (ตอนนี้ใช้ถ.เจริญเมือง จ.แพร่ คร่าวๆ)
- เบอร์โทรจริง (ตอนนี้ใช้ 091-234-5678 ตัวอย่าง)
- LINE ID จริง (ตอนนี้ใช้ @coffeemanah)
- เรื่องราว/จุดเด่นของร้านจริง (ตอนนี้ใช้เนื้อหาทั่วไป: คั่วสดทุกเช้า, Wi-Fi, มุมทำงาน)
- เมนูจริง + เมนูลับ
- มี Facebook/IG หรือไม่
